# Legacy Transition Inventory and Gate

SHIFT is a clean V3 product and does not read or migrate ColorShift settings.

The predecessor uses the name `ColorShift`, distributable `colorshift-anywhere.user.js`, and its own latest-release asset URL. SHIFT uses the separate `ExtraPotions/SHIFT` repository and `shift.user.js` update path.

The maintainer approved:

1. target repository `ExtraPotions/SHIFT`;
2. stable userscript/release asset `shift.user.js`;
3. distinct install, update, and download URLs;
4. coexistence with ColorShift rather than silent replacement.

The ColorShift repository, update path, and releases remain untouched.
